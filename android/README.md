# App Android — IPS Salud Vital

Aplicación nativa en Java para el portal del paciente.

## Funciones actuales
- Login de paciente contra la API.
- Consulta de citas del paciente autenticado.
- Consulta de notificaciones del paciente.
- Cierre de sesión.

## Prueba
Con el servidor activo en el PC y un emulador Android:
- Documento: `1022334455`
- Contraseña: `Paciente123`

Para teléfono físico cambia `ApiClient.BASE_URL` por la IP local de tu computador, por ejemplo `http://192.168.1.20:4000/api`.
